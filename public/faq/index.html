FAQ

Before you ask.

What is ActionRank?

An API that ranks an AI agent's tools for a given task, so the agent calls the right one first.

Does ActionRank call my tools?

No. It returns an order. Your agent still decides and makes every call itself.

What do I send it?

The task your agent is working on and the tools it has available, with their names and descriptions.

Do I need to change how my agent is built?

It is designed as a single step before tool selection, so it sits alongside whatever you already use.

Where does the name come from?

"Aethis" comes from aether, the invisible layer the Greeks believed everything moved through. The mark is a sky dome with three paths from one point. Only one reaches the light.

How do I get access?

Access is by request. Email yash@aethislabs.com with a line about your agent.
