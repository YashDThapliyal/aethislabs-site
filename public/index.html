      How it works

      One step before the agent acts.

      1. 1

        Send the task and the tools

        The request your agent is working on, plus the names and descriptions of the tools it can call.

      2. 2

        ActionRank scores each tool

        Every tool is scored against the task, so the likely right call rises to the top.

      3. 3

        Your agent calls the top tool first

        Your agent still makes every call. It just starts from a better place, and can fall back down the list if it needs to.

      Questions

      Before you ask.

      Does ActionRank call my tools?

      No. It returns an order. Your agent still decides and makes every call itself.

      What do I send it?

      The task your agent is working on and the tools it has available, with their names and descriptions.

      Do I need to change how my agent is built?

      It is designed as a single step before tool selection, so it sits alongside whatever you already use.
